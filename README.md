# おなかケア記録アプリ

腹痛が多い方向けに、毎日の食事・体調・便通/尿回数・便の状態・腹痛・ストレスを記録し、腹痛との関係を簡易分析するWebアプリです。

## できること
- 食事（朝食・昼食・間食・夕食）の記録
- 体調メモの記録
- 便通回数（未入力可）・尿回数の記録
- 便の具合の記録（未入力可）
- 腹痛レベル（0〜10）の記録
- ストレスレベル（0〜10）の記録
- 腹痛とストレス、便の具合、食事キーワードの関係を簡易分析

## ボタンについて
- `記録を保存`: 入力内容を保存します。
- `削除`: 記録一覧の対象行のみ削除します。
- `全データ削除`: すべての保存データを削除します。
- このアプリに `PRを表示` ボタンはありません（PRは開発作業管理用で、利用者向け機能ではありません）。

## 使い方
1. `index.html` をブラウザで開きます。
2. 今日の記録を入力して「記録を保存」を押します。
3. 「分析」欄に集計結果が表示されます（便通や便の具合が未入力でも利用できます）。
4. データはブラウザの LocalStorage に保存されます。

## 注意
- 分析はあくまで目安です。医療診断ではありません。
- 強い症状が続く場合は医療機関へ相談してください。
